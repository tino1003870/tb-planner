# TB Planner – Thunderbird Add-on

Thunderbird-native WBS/Gantt planning for VTODO tasks.

The add-on uses Thunderbird's calendar storage directly. No CalDAV URL,
username or password is configured in the add-on; synchronized Thunderbird
calendars are used as the data source.

## Installation

Use `about:debugging` → **This Thunderbird** → **Load Temporary Add-on**
and select the XPI.

## Features

- Thunderbird calendar selection
- VTODO loading
- WBS hierarchy
- Gantt timeline: day/week/month/calendar week
- Create, edit and delete tasks
- Start date and duration
- Progress
- Indent/outdent and move up/down
- JSON import/export
- Printing
